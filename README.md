# 🌡️ Website Konversi Suhu (Celsius → Fahrenheit)

Proyek frontend sederhana yang dibuat selama proses belajar bersama **RevoU**, berupa website konversi suhu dari derajat **Celsius (°C)** ke **Fahrenheit (°F)**.

## ✨ Fitur

- 🔄 **Konversi** suhu dari Celsius ke Fahrenheit secara real-time
- ♻️ Tombol **Reset** untuk mengosongkan input
- ↔️ Tombol **Reverse** untuk membalik arah konversi
- 📖 Penjelasan rumus konversi yang digunakan, langsung ditampilkan di halaman

## 🧮 Rumus Konversi

```
F = (C × 9/5) + 32
```

atau setara dengan:

```
F = (C × 1.8) + 32
```

1. Clone repository ini

## 🎯 Tujuan Proyek

Proyek ini dibuat sebagai latihan penerapan konsep dasar **DOM manipulation**, **event handling**, dan **logika konversi numerik** menggunakan JavaScript, sebagai bagian dari pembelajaran frontend web development di RevoU.
